# 🍽️ Restaurant Reservation System (MERN Stack)

A full-stack web application that allows users to browse a restaurant's menu and book a table online seamlessly.

---

## 🚀 Features
- **User Reservation:** Simple form for booking a table with date and time.
- **Responsive UI:** Fully mobile-friendly design using React and CSS/SCSS.
- **Backend Validation:** Secure data handling and validation using Express and Joi/Zod.
- **Database Integration:** Real-time data storage in MongoDB Atlas.
- **Sweet Alerts:** Beautiful notification pop-ups for success or error messages.

## 🛠️ Tech Stack
- **Frontend:** React.js, Vite, CSS/SCSS, Axios
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Icons & Fonts:** FontAwesome, Google Fonts
